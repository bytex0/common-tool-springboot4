# 本地缓存功能对照

| 原能力 | 当前入口及改进 | 验证 |
| --- | --- | --- |
| 过期、最大容量、初始容量扩展 | 原三个 protected 方法保留，构造延迟到子类就绪 | 可控时钟、容量及构造参数测试 |
| createCache 扩展 | 原入口保留，保证一次创建，递归初始化立即失败，失败可重试 | 并发加载、递归失败跨线程恢复 |
| onRemoval 扩展 | 原签名保留，既有子类覆盖继续生效 | 实际显式删除回调测试 |
| get/加载/put/remove/clear/size/stats | 全部保留，开启真实统计，空值和失败加载不缓存 | 单测及真实 CRUD/加载/过期接口 |
| 按类获取缓存 | getCache(Class) 保留为实例入口，多实例歧义明确报错 | 类型查找及双实例测试 |
| 原所有缓存的类型索引 | getCachesByType 提供原 Class 键视图，getAllCaches 保留新命名视图 | 类型视图及冲突测试 |
| 清空全部缓存 | clearAllCaches 保留为实例入口，不重置累计统计 | 单测及 HTTP 清空 |
| 原类名统计及十三个字段 | getCacheStatsByClassName 恢复原根键形状，命名统计同时保留 | 单测及 type-stats 真实接口 |
| 工厂生命周期 | 单例完成后注册，关闭后不能重新发布，不持锁清空缓存 | 生命周期及上下文隔离测试 |
| 注释与并发规范 | 初始化及生命周期显式锁；主代码和示例均接入 Checkstyle | 全量 validate |

接入调整：工厂由静态全局调用改为注入实例，避免不同上下文串扰；原类型映射对应
getCachesByType，原类名统计对应 getCacheStatsByClassName。同名或同类型歧义不再静默覆盖。
仅注册可识别的单例缓存；不保留提前实例化 Bean、暴露可变注册表等不安全行为。
这是源码接入调整，不承诺旧静态调用的二进制兼容；原缓存业务能力均有实际对应实现。
